# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: trato respetuoso e inclusivo, crítica dirigida a las ideas y no a las personas, y cero tolerancia con el
acoso. Las incidencias se reportan de forma privada a los mantenedores mediante un
[aviso de seguridad privado](https://docs.github.com/es/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
del repositorio (marcando que no es una vulnerabilidad) o por el canal indicado en el perfil del proyecto; se
atenderán con confidencialidad.
