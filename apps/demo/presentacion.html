Presentación para desarrolladores · 2026-10-10

@qhago/scanner

Lector de códigos de barras y QR para web, Node y Bun.
ZXing-C++ en WebAssembly, fusión multi-frame y detector IA opcional.

← → o espacio para avanzar · F pantalla completa · O índice

El problema

QuaggaJS / Quagga2

  • Solo códigos 1D, JS puro
  • 13,7 % de recall en los samples de ZXing
  • Sin QR, DataMatrix, PDF417, Aztec

Lo que queríamos

  • 13 formatos (los de BarcodeDetector)
  • Mejor que zxing-wasm en fotos difíciles
  • Cámara fluida: el hilo principal no trabaja
  • Misma API en navegador, Node y Bun
  • Migrar desde Quagga cambiando un import

Arquitectura

 Hilo principal                         Web Worker (uno, reutilizado)
┌───────────────────────────┐          ┌──────────────────────────────────────────┐
│ decode() · createScanner()│  frames  │ ScannerSession                           │
│ <qhago-scanner> · polyfill│ ───────▶ │  ├─ cascada ZXing (WASM, 319 KB gzip)    │
│ quagga-compat             │          │  ├─ tracker + fusión multi-frame         │
│                           │ ◀─────── │  ├─ escalado: ROI thorough / barrido     │
│ eventos detect / track …  │ eventos  │  └─ plugins (p. ej. detector IA)         │
└───────────────────────────┘          └──────────────────────────────────────────┘
        Node / Bun: mismo motor (build node, PNG/JPEG con stb_image), sin worker
  • Una ABI C (sa_*) entre JS y C++: opciones como Int32Array, resultados en JSON.
  • 3 rutas de captura: MediaStreamTrackProcessor → requestVideoFrameCallback → inline (sin worker).

Dentro del motor: la cascada

strategypasadas
fastbase (tryHarder)
balanced+ CLAHE, unsharp, ×2, inversión
thorough+ ×0,5, recortes, más rotaciones

Para en cuanto hay maxSymbols lecturas válidas.

  • Validación: checksums + filtros de longitud (validateChecksums)
  • UPC-A ⇄ EAN-13 normalizado
  • confidence: 2D = 1 (Reed-Solomon); 1D = líneas de escaneo coincidentes
  • Paridad WASM ≡ nativo: 11 388 combinaciones idénticas

En vídeo: tracking y fusión

  • Tracker: cada símbolo (leído o no) recibe un trackId estable entre frames.
  • Fusión (ADR-05): Code39/93, Codabar, ITF y Code128 cortos piden 2 frames coincidentes; el resto, 1.
  • Escalado: un track sin leer 2 veces → thorough en su ROI; nada en k frames → barrido por zonas.
  • Scheduler: 1 frame en vuelo, ritmo ≈ 1,2 × lo que tarda el motor (no se acumula retraso).
frame ─▶ cascada ─▶ tracker ─▶ fusión ─┬─▶ "candidate" (aún sin consenso)
                                       ├─▶ "detect"    (confirmado, una vez por cooldown)
                                       ├─▶ "track"     (posición nueva de algo ya leído)
                                       └─▶ "lost"      (el track desaparece)

Formas de usarlo

1 · decode(): imágenes y archivos

decode() en el navegador

import { decode } from "@qhago/scanner";

input.onchange = async () => {
  const results = await decode(input.files[0], {
    formats: ["qr_code", "ean_13"],   // default: los 8 de ADR-05
    strategy: "thorough",              // fast | balanced | thorough
  });
  for (const r of results)
    console.log(r.format, r.text, r.cornerPoints, r.confidence);
};
  • Acepta File/Blob, ArrayBuffer, <img>, <canvas>, ImageBitmap, ImageData, VideoFrame, { data, width, height, format }.
  • En el hilo principal delega en un worker interno automáticamente (worker: false para desactivarlo).
  • region (px), maxSymbols, timeBudgetMs, signal (AbortController), includeErrors.

decode() en Node y Bun

import { readFile } from "node:fs/promises";
import { decode, isScanError } from "@qhago/scanner";   // export condition "node" / "bun"

try {
  const [r] = await decode(await readFile("etiqueta.png"));  // PNG / JPEG
  console.log(r?.text);
} catch (e) {
  if (isScanError(e)) console.error(e.code, e.docsUrl);    // INVALID_INPUT, ABORTED…
}
  • Node ≥ 22.12 y Bun ≥ 1.2. Mismo motor y mismos resultados (snapshot idéntico en 571 imágenes).
  • Para paralelizar lotes: una instancia por worker_threads / Bun.Worker.
  • createScanner() en Node lanza ScanError("UNSUPPORTED") (no hay cámara).

Formas de usarlo

2 · createScanner(): cámara

Escáner de cámara

import { createScanner, mapToElement } from "@qhago/scanner";

const scanner = createScanner({
  video: document.querySelector("video"),
  formats: ["ean_13", "qr_code"],
  roi: { x: 0.1, y: 0.3, width: 0.8, height: 0.4 },   // normalizada 0..1
  fusion: { duplicateCooldownMs: 2000 },
});

scanner.on("detect", ({ result }) => addToCart(result.text));
scanner.on("track", ({ result }) =>               // overlay: vídeo → CSS
  draw(result.trackId, mapToElement(result.cornerPoints, video)));
scanner.on("error", ({ error }) => show(error.code)); // PERMISSION_DENIED…

await scanner.start();

Control de la cámara y ciclo de vida

await scanner.start({ signal });
scanner.pause();  scanner.resume();
await scanner.stop();
scanner.destroy();         // sin fugas

scanner.getCapabilities(); // torch, zoom
await scanner.setTorch(true);
await scanner.setZoom(2);
const cams = await scanner.listCameras();
await scanner.switchCamera(cams[1].deviceId);
  • Elige la cámara trasera principal (no la gran angular) por capabilities.
  • Recuerda la última cámara (rememberCamera).
  • stream: usa un MediaStream tuyo.
  • frameStats: true → eventos frame con fps y ms.
  • getPermissionState() antes de pedir permiso.

3 · Sin escribir JS de cámara

<qhago-scanner>: Custom Element

<qhago-scanner formats="ean_13,qr_code" roi="0.1,0.3,0.8,0.4"
               torch-button switch-camera-button beep vibrate lang="es">
</qhago-scanner>

<script type="module">
  import "@qhago/scanner/ui";            // o el dist/browser/ui.js de un CDN
  document.querySelector("qhago-scanner")
    .addEventListener("detect", (e) => console.log(e.detail.text));
</script>
  • Shadow DOM, ::part() y variables --qhago-accent / --qhago-mask.
  • Overlay animado por trackId, aria-live, labels es/en; axe-core sin violaciones.
  • Atributo paused para arrancar bajo demanda; SSR-safe.

Polyfill de BarcodeDetector

import { installPolyfill } from "@qhago/scanner/polyfill";
installPolyfill();                      // solo si el navegador no lo trae

const det = new BarcodeDetector({ formats: ["qr_code"] });
const [code] = await det.detect(video);  // API estándar W3C
console.log(code?.rawValue, code?.cornerPoints);
  • Código escrito para Chrome Android funciona en Firefox, Safari y Node (también exporta para Node/Bun).
  • Acepta todo ImageBitmapSource, incluidos <video> y SVGImageElement; TypeError donde la spec lo exige.
  • Alternativa: decode(img, { engine: "auto" }) usa el nativo si soporta los formatos.

Migrar desde Quagga2

- import Quagga from "@ericblade/quagga2";
+ import Quagga from "@qhago/scanner/quagga-compat";

Quagga.init({
  inputStream: { type: "LiveStream", target: "#interactive" },
  decoder: { readers: ["ean_reader", "code_128_reader"] },
}, (err) => !err && Quagga.start());

Quagga.onDetected((r) => console.log(r.codeResult.code));
Quagga.onProcessed((r) => Quagga.ImageDebug.drawPath(r.box, { x: 0, y: 1 },
                                Quagga.canvas.ctx.overlay, { color: "blue" }));
  • box, boxes, line, canvas.ctx.overlay, decodeSingle, CameraAccess; VIN en code_39_vin_reader.
  • Opciones que no aplican (locator.patchSize…) avisan una vez. Ejemplo: apps/examples/quagga-migration.

Interpretar el contenido: parsers

import { parseGS1, parseQRContent, parseAAMVA, parseISO15434 } from "@qhago/scanner/parsers";

parseGS1("(01)07501031311309(17)261231(10)LOTE1");
// { gtin: "07501031311309", expiry: "2026-12-31", batch: "LOTE1", ais: {…}, errors: [] }

parseQRContent("WIFI:T:WPA;S:Casa;P:clave;;");
// { type: "wifi", ssid: "Casa", password: "clave", security: "WPA", hidden: false }

parseAAMVA(pdf417.text);     // licencias de conducir EE. UU./Canadá → nombre, fechas ISO…
parseISO15434(datamatrix.text); // sobres "[)>" con Data Identifiers o AIs GS1

Funciones puras (4,3 KB gzip), sin motor: sirven también en servidor. GS1 acepta paréntesis, FNC1 y ]C1/]d2/]Q3.

5 · Detector IA opcional (experimental)

import { createScanner } from "@qhago/scanner";
import { aiDetector, aiWorker } from "@qhago/ai";

createScanner({ workerFactory: aiWorker, plugins: [aiDetector({ when: "fallback" })] });
  • Red propia (CenterNet-lite, 0,24 GMAC, 330 KB INT8) que propone 4 esquinas; el motor rectifica y ZXing lee. No puede inventar lecturas.
  • Corre en el mismo worker (ONNX Runtime Web, WASM); solo cuando el clásico no lee, como mucho cada 300 ms.
  • Fotos reales: +7,0 pp de recall (desenfocadas ×2,8), 0 lecturas falsas extra; ~40 ms por inferencia. Sin publicar hasta medirlo en móvil.
  • Interfaz de plugins abierta: startWorkerHost({ plugins }) en @qhago/scanner/worker-host.
